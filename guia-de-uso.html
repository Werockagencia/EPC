Guía de uso — Panel de usuario.

Credenciales de prueba y resumen de lo construido hoy para el desarrollo WordPress de la EPC. Este contenido es interno, para la sesión de revisión del equipo — no forma parte del sitio público.

El panel de usuario ya tiene login real y 3 roles con navegación y permisos distintos, funcionando sobre WordPress (listos para conectar a la API de Integra cuando esté disponible). Pruébalos en http://localhost:8890/login/ sobre el entorno local del computador donde se construyó.

2. Cómo ver el sitio hoy

Abrir una terminal en la carpeta del proyecto

Desktop → We Rock → Desarrollos Wordpress → EPC Cajica → wordpress

Levantar el servidor local

Correr el comando documentado en README.md de la carpeta del proyecto (WordPress + SQLite, sin instalar nada adicional).

Abrir en el navegador

http://localhost:8890/ para el sitio público, http://localhost:8890/login/ para el panel con cualquiera de los 3 usuarios de arriba.

El sitio corre en el computador local (todavía no está publicado en internet) — para la sesión de hoy se navega en vivo desde acá. El wireframe de referencia visual, ya aprobado, sí es público: werockagencia.github.io/EPC.
